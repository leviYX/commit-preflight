# 提交前检查

- 默认检查暂存区（staged）。只有明确要求查看未暂存修改才使用 unstaged，且这不代表下一次普通提交。
- scan_changes 返回确定性统计和启发式内容扫描；git_changes 仅返回统计，不做内容扫描。
- 行数口径：新增+删除，包含注释、空行。替换一行通常计两行；纯重命名可以是零行；二进制行数未知，不用零行推断其变更小。
- 同时报告全量统计和排除后的统计。排除范围由 .dsh-preflight.json 决定；不可将排除内容声称为已检查。
- 对疑似密钥只引用位置和规则，不输出其值。对调试语句、待办注释需要人工确认，不直接声称代码有缺陷。
- 只在用户要求运行检查时调用 run_project_check，显式指定已有 lint/typecheck/type-check/check/test 脚本。脚本及其前后置脚本会执行仓库代码，可能生成文件；这个允许列表不是脚本沙箱。
- 检查脚本读取工作区；部分暂存时，成功结果不能证明暂存内容通过。
- 不修改暂存区、不自动提交、不静默提高阈值或扩大排除范围。命令失败或超时必须报告为未完成。
